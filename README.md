# FireFinance - Research Milestone

## About the Project

For my CSCE 490 Research Milestone, I created a personal finance dashboard called FireFinance. The idea behind this project was to get some experience with technologies that could be useful for my group's capstone project, which focuses on financial literacy and investing.

The app lets users enter their monthly income and expenses to see how much money they have left over. It also includes a chart that breaks down spending and a savings goal tracker.

## Technologies I Used

- **React:** I used React to build the different parts of the dashboard and make the app interactive.
- **JavaScript:** I used JavaScript for calculations like total expenses, remaining income, and savings percentages.
- **Vite:** I used Vite to set up and run the application locally.
- **Recharts:** I used Recharts to create the chart showing where users are spending their money.
- **CSS:** I used CSS to customize the appearance of the dashboard.
- **GitHub:** I used GitHub to keep track of my changes throughout the project.

## Features

Some of the features I worked on include:

- Entering monthly income and expenses
- Automatically calculating how much money is left over
- Showing expenses in a doughnut chart
- Adding subscriptions as an expense category
- Setting a monthly savings goal
- Displaying progress toward that savings goal
- Resetting the savings goal back to its default amount

## What I Learned

This project helped me get more familiar with React and how it works with JavaScript. One thing I learned was how React components can be separated into different files while still working together.

I also got more practice using VS Code, running a React application locally, and making changes through GitHub. I learned how React state can update the information displayed on the page whenever a user changes an input.

One challenge was figuring out which files I needed to edit when adding a new feature. For example, adding the subscriptions category required changes to the budget form, the calculations, and the chart.

## How to Run the Project

1. Download or clone this repository.
2. Make sure Node.js is installed.
3. Open the project folder in VS Code.
4. Run `npm install` in the terminal.
5. Run `npm run dev`.
6. Open the local address shown in the terminal.

## How This Relates to Our Capstone

Our group's capstone project involves creating an application that helps people learn about personal finance and investing.

I think React could be a good choice for our project because it makes it easier to build interactive pages and organize different features into components. Recharts could also be useful for displaying financial information in a way that's easier for users to understand.

This prototype is pretty basic compared to what our final capstone application will be, but it gave me a better understanding of how these technologies could work together.
